# POL003: klaudiush command changes policy

## Error

A shell command runs a klaudiush command that changes klaudiush policy: its configuration (`init`), overrides (`disable`, `enable`), the bypass setting (`bypass skip`, `bypass enforce`, `bypass notify`), state or backups (`backup create`, `restore`, `delete`, `prune`, `audit cleanup`, `patterns reset`, `debug crash clean`), automatic repairs (`doctor --fix`) or the binary (`update`).

## Why this matters

These commands change what klaudiush enforces without touching a file the agent names, so they are protected like the files themselves.

## How to fix

Ask the user to run the command. Read-only commands stay available to the agent: `evidence run` and `status`, `doctor` without `--fix`, `debug`, `audit list`, `backup list`, `bypass status`, `patterns list`, `version`.

## Configuration

Enabled with protection:

```toml
[protection]
enabled = true
```

An exception token bypasses POL003 only when the configuration has an `[exceptions.policies.POL003]` entry.
