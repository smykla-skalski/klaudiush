# GIT010: Missing required flags

## Error

Git commit is missing required flags (typically `-s` and `-S`).

## Why this matters

The `-s` (signoff) flag records Developer Certificate of Origin compliance. The `-S` (GPG sign) flag cryptographically verifies authorship. Both are required by default.

## How to fix

Add the required flags:

```bash
git commit -sS -m "message"
```

Or use the long forms:

```bash
git commit --signoff --gpg-sign -m "message"
```

## What is checked

klaudiush checks a commit where `git` is the command word of a simple command: at the start of the command line, after `&&`, `||`, `;`, `|` or a newline, in a subshell, `$(...)` or backticks, after environment assignments, behind a wrapper such as `env`, `command`, `sudo`, `time`, `nohup`, `timeout`, `xargs` or `exec`, behind global options such as `-C <dir>` and `-c key=value`, in a `bash -c`, `sh -c` or `zsh -c` string, and in a heredoc or here-string fed to a shell (`bash <<EOF`). A script the command runs (`bash script.sh`) is read, and the commits in it are checked the same way.

Text that only contains the words `git commit` is not a commit, so it is not checked:

- arguments of other programs (`echo`, `printf`, `grep`, `curl`, `zakwas propose add-permission deny 'git commit'`)
- heredocs and here-strings fed to programs that are not shells (`cat <<EOF > file`, `tee`); one fed to an interpreter such as `python3 - <<EOF` is read as code, and a string in it is a command only when the code can run it
- strings in interpreter code that only print them, or only write them to a file while nothing else on the line runs files, such as a test fixture written by Python
- quoted arguments and comments

Only runners that take a command in their arguments (`ssh`, `tmux`, `mise exec`, `docker run`, `kubectl exec`, and similar) have their arguments scanned for a commit.

## Configuration

Set which flags are required in `config.toml`:

```toml
[validators.git.commit]
required_flags = ["-s", "-S"]  # Default: both signoff and GPG sign
```

Require only signoff:

```toml
[validators.git.commit]
required_flags = ["-s"]
```

Disable flag requirements:

```toml
[validators.git.commit]
required_flags = []
```

## Hook output

When this error is triggered, klaudiush writes JSON to stdout:

**permissionDecisionReason** (shown to Claude):
`[GIT010] Git commit is missing required flags (-s, -S). Add -sS flags: git commit -sS -m "message"`

**systemMessage** (shown to user):
Formatted error with fix hint and reference URL.

**additionalContext** (behavioral guidance):
`Automated klaudiush validation check. Fix the reported errors and retry the same command.`
