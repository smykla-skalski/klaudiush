# GIT018: PR merge signoff missing

## Error

The merge commit body has no `Signed-off-by` trailer.

## Why this matters

The `Signed-off-by` trailer ties a commit to an identity, which matters for DCO compliance and author attribution on squash merges. Some organizations require it on every commit.

## How to fix

### Add signoff when merging

Pass the signoff in the `--body` flag:

```bash
gh pr merge <number> --squash --body "$(cat <<'EOF'
Summary of changes.

Detailed description of what was changed and why.

Signed-off-by: Your Name <your.email@klaudiu.sh>
EOF
)"
```

### Merging through the REST API

`PUT /repos/{owner}/{repo}/pulls/{number}/merge` with `merge_method=squash`, sent by `gh api`, `curl`, `wget`, httpie or `xh`, gets the same check. The `commit_message` field plays the part of `--body`:

```bash
gh api -X PUT repos/owner/repo/pulls/123/merge -f merge_method=squash -f commit_message="$(cat <<'EOF'
Summary of changes.

Signed-off-by: Your Name <your.email@klaudiu.sh>
EOF
)"
```

A `commit_message` read from a file (`-F commit_message=@file`) is treated like `--body-file` and not inspected. Without `merge_method`, the REST API creates a merge commit, which is not checked, the same as `gh pr merge --merge`.

When `commit_message` or `merge_method` arrives both in the request body and in the query string, as happens when `gh api --input` sends `-f` fields as query parameters, every value is checked: each readable `commit_message` must carry the signoff, and the merge is checked as a squash if any `merge_method` value squashes. GitHub does not document which value it reads, so one passing value is not enough.

### Check your git identity

Confirm your name and email are set:

```bash
git config user.name
git config user.email
```

Update if needed:

```bash
git config user.name "Your Name"
git config user.email "your.email@klaudiu.sh"
```

## Configuration

Require signoff for merge commits:

```toml
[validators.git.merge]
require_signoff = true
```

Disable the signoff requirement:

```toml
[validators.git.merge]
require_signoff = false
```

Pin the expected signoff identity:

```toml
[validators.git.merge]
expected_signoff = "Your Name <your.email@klaudiu.sh>"
```

## Examples

### Squash merge with signoff

```bash
gh pr merge 123 --squash --body "$(cat <<'EOF'
feat(api): add user authentication

Implements JWT-based authentication with refresh tokens.
Includes middleware for route protection and token validation.

Closes #42

Signed-off-by: Developer Name <dev@klaudiu.sh>
EOF
)"
```

### Auto-merge with signoff

```bash
gh pr merge 123 --auto --squash --body "$(cat <<'EOF'
fix(parser): handle edge cases

Handles empty input and malformed JSON gracefully.

Signed-off-by: Developer Name <dev@klaudiu.sh>
EOF
)"
```
