# GIT026: Push to blocked branch

## Error

The `git push` command updates a branch that is on the blocked list, or a target klaudiush cannot check against the list (the current branch of a detached or unreadable repository, a matching `:` refspec, `--all`).

## Why this matters

Direct pushes to protected branches such as `main` or `master` bypass review. Blocking them keeps changes on a branch and in a pull request.

## How to fix

Push a feature branch and open a pull request:

```bash
git switch -c feat/my-change
git push -u origin feat/my-change
```

## What is checked

klaudiush checks a push where `git` is the command word of a simple command: at the start of the command line, after `&&`, `||`, `;`, `|` or a newline, in a subshell, `$(...)` or backticks, after environment assignments, behind a wrapper such as `env`, `command`, `sudo`, `time`, `nohup`, `timeout`, `xargs` or `exec`, behind global options such as `-C <dir>` and `-c key=value`, in a `bash -c`, `sh -c` or `zsh -c` string, and in a heredoc or here-string fed to a shell (`bash <<EOF`). A script the command runs (`bash script.sh`) is read, and the pushes in it are checked the same way.

Text that only contains the words `git push` is not a push, so it is not checked:

- arguments of other programs (`echo`, `printf`, `grep`, `curl`, `zakwas propose add-permission deny 'git push'`)
- heredocs and here-strings fed to programs that are not shells (`cat <<EOF > file`, `tee`); one fed to an interpreter such as `python3 - <<EOF` is read as code, and a string in it is a command only when the code can run it
- strings in interpreter code that only print or write them
- quoted arguments and comments

Only runners that take a command in their arguments (`ssh`, `tmux`, `mise exec`, `docker run`, `kubectl exec`, and similar) have their arguments scanned for a push.

## Configuration

```toml
[validators.git.push]
blocked_branches = ["main", "master"]
```

## Hook output

When this error is triggered, klaudiush writes JSON to stdout:

**permissionDecisionReason** (shown to Claude):
`[GIT026] Branch 'main' is blocked for push operations. Push to a different branch or create a PR`

**systemMessage** (shown to user):
Formatted error with fix hint and reference URL.

**additionalContext** (behavioral guidance):
`Automated klaudiush validation check. Fix the reported errors and retry the same command.`
