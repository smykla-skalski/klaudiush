# MCP005: MCP provenance unknown

## Error

An MCP tool call carries no information about which server serves it, and `mcp_trust.unknown_provenance` is `block` (the default) or `warn`. This is every MCP call from Codex and opencode, from Claude Code before 2.1.274, and from Gemini CLI when `mcp_context` has no transport.

## Why this matters

Without provenance the only server identity is the name in the tool name, which any configured server can claim. klaudiush does not fall back to it.

## How to fix

Use a tool that is not served over MCP, or ask the user to update the harness or to choose another action for calls without provenance:

```toml
[mcp_trust]
unknown_provenance = "warn"   # or "allow"
```

## Configuration

```toml
[mcp_trust]
enabled = true
unknown_provenance = "block"
```

An exception token bypasses MCP005 only when the configuration has an `[exceptions.policies.MCP005]` entry.
